When I replaced an office's main server, a few older machines became free. Instead of wiping one and handing it back, I turned it into a place to learn Linux.

## The setup

The PC has a 480 GB SSD. I set it up as a UEFI dual boot with Windows 10 Home and [Omarchy](https://omarchy.org), an opinionated Arch Linux setup. The Limine bootloader starts Windows by default, so the machine behaves like before unless you choose otherwise.

That default matters. A learning environment should never get in the way of work. If something breaks in Linux, the person can restart and carry on in Windows.

## Why in English

I left Omarchy in English on purpose. Most Linux documentation, error messages and forum answers are in English, and I want the person learning to be able to search for them.
