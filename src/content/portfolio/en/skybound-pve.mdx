I started with a multiplayer flight prototype and kept the flight controls and 3D island for a single-player arcade game. You can start a run from the browser and see how long you last against successive waves. High scores are stored locally.

The game uses Three.js and React Three Fiber for the scene, Rapier for physics, and Zustand for state. I wrote about [how I used Gemini and Codex to build it](/en/blog/vibecoding-skybound-pve).
