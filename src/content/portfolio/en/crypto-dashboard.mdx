Crypto Dashboard is a React interface for tracking cryptocurrencies with Binance data. It shows live prices, volume, change, and historical charts for major pairs.

The app combines API requests with WebSockets to keep the view current. It includes search, favorites, and range controls for quickly analyzing each asset.
