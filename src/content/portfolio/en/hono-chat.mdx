I built Hono Chat to see how WebSockets fit alongside an HTTP API. Each room has its own URL. Sharing that URL gives someone a way into the conversation.

Next.js renders the interface. A Hono backend handles live messages over WebSockets, and PostgreSQL stores the message history so it survives a reload.
