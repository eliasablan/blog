Crypto Dashboard es una interfaz en React para seguir criptomonedas con datos de Binance. Muestra precios en vivo, volumen, variación y gráficos históricos de los principales pares.

La app combina consulta a la API con WebSockets para mantener la vista actualizada. Incluye búsqueda, favoritos y controles de rango para analizar cada activo con rapidez.
