Construí Hono Chat para aprender a combinar WebSockets con una API HTTP. Cada sala tiene su propia URL. Quien recibe ese enlace puede entrar a la conversación.

Next.js renderiza la interfaz. El backend con Hono recibe y distribuye los mensajes por WebSockets, y PostgreSQL guarda el historial para que siga disponible al recargar.
