Hono Chat es una app de mensajería en tiempo real con salas basadas en URL. Cada sala mantiene conversaciones persistentes y permite entrar sin fricción desde un enlace.

El frontend usa Next.js, React y TypeScript. El backend está construido con Hono, WebSockets para mensajes bidireccionales y PostgreSQL para persistencia.
